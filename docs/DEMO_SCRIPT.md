# Settleit — Demo Script (3 minutes)

Prereqs: StudioNet deployment done, three wallets (Claimant, Respondent, Spectator).

1. **Hook (15s)** Home page: "GOT AN ARGUMENT? SETTLEIT."
2. **Claimant (45s)** Challenge → Roommates → paste respondent address → title "The Chicken in the Fridge" → question → statement → one evidence text → Public → acknowledge → Sign.
3. **Respondent (30s)** Switch wallet, open the link, show "YOU'VE BEEN CHALLENGED.", write the response, lock it in.
4. **Jury (45s)** "Summon the jury". Point at the tracker: wallet → submitted → processing. Call out **Accepted — provisional** and that Finalized appears only when the network reports it.
5. **Reveal (20s)** Verdict banner, fault bars, remedy, reason codes.
6. **Humans (20s)** Spectator wallet votes; show humans-vs-jury label.
7. **Share (5s)** Copy link.

Say plainly: StudioNet is a test network; the jury only knows what was submitted.
